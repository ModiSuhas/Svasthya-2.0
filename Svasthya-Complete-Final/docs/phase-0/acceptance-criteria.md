# Phase 0 — Release acceptance criteria

- Each in-scope workflow has an owner and a clinic-approved success path.
- Each role has a reviewed permission row for every protected capability.
- Patient, clinical, lab, prescription, and pharmacy fields have documented purpose and access.
- Failed, duplicate, cancelled, and corrected records have a defined handling path.
- The clinic has selected the initial facility, hosting operator, launch region, retention schedule, and support contact.
- Patient-facing notices and staff operating procedures have been reviewed by the organization and qualified advisers.
- No sample data is mistaken for production data; no production patient data is placed in development or staging.
